# 이전 패키지 단계의 자기 확인 항목

참고용 목록이며 현재 문서 작업에서 시험·포장·배포를 수행하라는 지시가 아닙니다. 실제 확인하지 않은 항목은 미실행으로 남깁니다. 예시 캡처 이름이 있다는 사실은 파일 존재나 성공의 증거가 아닙니다.

| 항목 | 확인 대상 | 기존 캡처 식별자 |
|---|---|---|
| P3 | 해당 서버 API의 인증 거절 | P3-1.png, P3-2.png |
| P4 | 구현된 AI 호출 상한 | P4-1.png, P4-2.png |
| P5 | 공식 위협정보 원천과 조회 시각 | P5-1.png, P5-2.png |
| P7 | 별도 승인된 새 배포의 환경·완료·화면 | P7-1.png, P7-2.png, P7-3.png |

현재 루트 AI·위협정보 API는 501 뼈대이므로 P4/P5 성공을 기록하지 않습니다. 실제 기록에는 커밋·환경·행동·응답·시각·실패 이유를 붙이고 비밀번호·키·타인 정보는 제외합니다. 합성 시험은 합성이라고 명시합니다.

Claire 로컬 앱의 현행 확인 절차는 [STUDENT_RUNBOOK.md](../on-client/docs/STUDENT_RUNBOOK.md)이며 이 패키지 표와 구분합니다. 기존 캡처·제출물은 유지합니다.
