# 이전 단계 패키지 안내 — 참고 전용

이 폴더는 루트 1–12단계 방어전의 패키지 자료입니다. 현재 Claire는 기존 `on-client` 프로젝트 폴더에서 실행하며 설치 프로그램·포장·Vercel 배포가 필요하지 않습니다. 실제 로컬 실행은 [앱 안내](../on-client/README.md)를 따릅니다.

## P7 배포 항목의 범위

수업의 **새 Vercel 프로젝트** 검증은 별도 배포 작업입니다. 현재 작업에서 프로젝트를 만들거나 환경변수를 복사하거나 배포하지 않습니다. 일반 빌드는 **Vercel이 제공하는 저장소·커밋·배포 URL 정보**를 검증하므로 로컬 정적 확인용 빌드와 같지 않습니다. 정본은 [빌드 구현](../scripts/build-public.mjs)과 [배포 설정](../vercel.json)입니다.

배포가 별도 승인되면 그때의 소스·배포 환경·실제 응답을 확인해야 합니다. 설정 파일의 공개 URL이 현재 배포 성공의 증거는 아닙니다. [SELF-CHECK.md](SELF-CHECK.md)의 캡처 이름은 확인 항목 식별자이지 완료 증거가 아닙니다.

## 현재 구현 상태

루트 `api/ai.js`, `api/threat-intel.js`는 501 미구현 응답입니다. 로컬 앱의 조건부 AI/OSV 기능과 혼동하지 않습니다. 원 수업 함수 기준표, 단계별 API 확장, 실제 커밋 변경 파일 목록은 서로 다른 목적의 JSON입니다.

기존 학생 자료·DB·제출물을 지우지 않습니다. 비밀은 운영 비밀 저장소에서 관리하며 문서·캡처·커밋에 넣지 않습니다. 이 문서는 배포·심판 통과·제품 완성을 선언하지 않습니다.
