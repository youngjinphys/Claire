# 예제와 실제 실행의 구분

현재 로컬 앱 예제는 `on-client` 폴더의 `npm run demo`입니다. 서버를 켠 뒤 `/` 또는 `/dashboard.html`을 엽니다. 예제는 SDP의 가상 신원·판정·사건이며 실제 원천 연결이 아닙니다. 자원 API의 OS 관측과 사용자가 고른 파일은 별도 출처입니다.

루트 설정에 기록된 공개 주소는 현재 응답·배포 성공을 확인한 링크라고 간주하지 않습니다. 현재 작업은 배포를 수행하지 않습니다. [실행·종료 안내](../on-client/docs/STUDENT_LAUNCH_GUIDE.md)와 [확인 순서](../on-client/docs/STUDENT_RUNBOOK.md)를 사용합니다.
