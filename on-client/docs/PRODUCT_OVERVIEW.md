# Claire의 기능과 관측 범위

Claire는 이 저장소의 `on-client` 로컬 앱입니다. Node 서버와 브라우저에서 자기 범위의 자료를 표시합니다. 설치 프로그램이나 Workbench 상시 실행은 필요하지 않습니다. 루트 방어전의 서버 함수·자료실은 별도 실행 대상입니다.

## 현재 화면

| 화면 | 기능 | 출처 |
|---|---|---|
| 기존 `/` | 보호 현황, 업무 앱 판정, 보안 기록, 학생 표시, 연결·도움정보 | `public/index.html`, `public/app.js`, `student/extension.mjs` |
| 통합 `/dashboard.html` | 네트워크·방화벽·Windows 기록·SDP 네 카드, 자원 측정·추이·기록 | `public/dashboard.*`와 기존 `hostPanel()` 재사용 |
| 파일 관측 | 네트워크 구성, OS별 방화벽 조회, Windows 로그 집계 | 일반 권한 CLI의 사용자가 선택한 JSON |
| 로컬 자원 | CPU, 메모리, 앱 파일시스템 여유 | `src/local-pc-metrics.mjs` |
| 조건부 원천 기능 | SDP 조회·판정, AI 설명·학습지원, OSV 조회, 사람 확인 조치 | 서버에서 별도 설정·권한·응답을 검증 |

## 반드시 분리할 판단

PC 조회 성공, SDP 연결, AI 앱 승인, 모델 목록 접근, 사건 설명, 조치 접수와 실제 효과는 다른 결과입니다. AI는 설명/제안을 제공하고 조치를 자동 집행하지 않습니다. 조치 경로가 코드에 존재해도 기본 실행은 미지원일 수 있습니다.

`connected` 모드 문자열은 구성된 어댑터를 뜻할 수 있으며 개별 원천 응답의 성공까지 증명하지 않습니다. DEMO는 가상 SDP 자료입니다. 사용자 선택 JSON은 서명된 기기 증명이 아닙니다. OS 경고·오류 건수와 자원 사용률은 공격·침해 판정이 아닙니다.

## 구현과 외부 운영의 경계

기본 연결 없음, 오류·부분 조회·해당 없음, 제한된 범위의 실제 0건을 구분합니다. 다른 서비스의 자격을 복사하거나 키 입력 UI로 연결을 우회하지 않습니다. 승인되지 않은 패키지 이름을 외부 취약점 서비스로 보내지 않습니다.

수업 포털의 채점 방식·순위·마감 정책은 이 저장소의 앱 코드로 확인할 수 없습니다. 로컬 문서가 현재 공식 정책을 대신하지 않으며, 단계 완료와 운영 연결도 별도 증거가 필요합니다.
