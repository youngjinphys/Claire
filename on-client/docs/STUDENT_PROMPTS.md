# 현재 Claire를 개선할 때 사용하는 요청 틀

현재 구현을 다시 만드는 프롬프트 대신, 고정한 HEAD와 변경 범위를 먼저 확인합니다. 단계별 원문 학습 항목은 [CURRICULUM.json](CURRICULUM.json), 이전 장문 프롬프트는 [보존본](../../docs/history/STUDENT_PROMPTS_BEFORE_2026-11-06.md)에 있습니다. 이 문서가 외부 공식 채점 기준을 재정의하지 않습니다.

## 공통 요청

> 현재 main의 코드·테스트를 먼저 확인하라. 기존 프로젝트와 제출물을 보존하고 새 브랜치를 만들지 말라. 변경 파일과 이유를 먼저 제시하라. 같은 기능이 있으면 재사용하라. 수업 공통 화면·서버는 승인 없이 변경하지 말라. 값의 출처·단위·시각·실패 이유를 구별하고 DEMO나 시험 값을 실제 PC 결과로 표시하지 말라. 포장·배포·관리자 권한·공격 시험을 실행하지 말라. 실행한 검증과 미실행 항목을 나누고 재현 명령을 남겨라.

## 현재 소스에 맞는 점검 순서

| 학습 항목 | 현재 점검 대상 | 성공으로 오해하지 않을 것 |
|---|---|---|
| 신원·기기·세션 | renderIdentity와 원천 응답 | PWA 설치·PC 보고서가 SDP 승인임 |
| 업무 앱 판정 | renderDecision, allow/deny/challenge/unknown | 정책 allow가 실제 앱 접속 성공임 |
| 기록·상태 | renderEvents/renderStatus, 필터·오류·빈 결과 | 실패/미연결이 0건임 |
| AI 연결·설명 | 승인, 모델 목록, 사건 근거 결속 | configured가 권한/추론 성공임 |
| 조치 | 준비·사람 확인·접수·효과 관측 | ACK 또는 AI 제안이 효과임 |
| 패키지 조회 | 승인 목록·정확 버전·부분 실패 | none_found가 전체 안전임 |
| 문서·재현 | 현재 명령·소스·동일 커밋 결과 | 과거 PASS와 다른 소스의 결과를 합산함 |

호스트 관측은 `hostPanel()`과 기존 수집기를 재사용합니다. 개선 요청에는 미조회·대기·부분 실패·오래된 보고서·동일 시각 상충·키보드 복원 같은 구체적인 경우를 포함합니다. 현재 미해결 문제는 [한계 문서](../../docs/CURRENT_LIMITATIONS.md)를 기준으로 하며 계획을 구현 완료로 바꾸어 적지 않습니다.
