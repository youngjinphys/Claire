# Claire 기능 확인 안내

문서 제목의 “최종”은 완성 인증이 아닙니다. 현재 패키지는 `on-client/package.json`의 0.2.11이며, 소스·CI·현장 관측·공식 접수를 분리합니다. 오래된 단계별 운영 개방 예상과 과거 시험 횟수는 현행 안내에서 제외했습니다.

## 설명서로 재현할 범위

[실행 안내](STUDENT_LAUNCH_GUIDE.md)에서 Windows/macOS/Linux의 기본 실행을, [제품 개요](PRODUCT_OVERVIEW.md)에서 화면별 기능을, [구성도](STUDENT_ARCHITECTURE.md)에서 소스와 데이터 흐름을 확인합니다. 구체적인 순서와 통과/실패의 의미는 [운영 확인 순서](STUDENT_RUNBOOK.md)를 따릅니다.

| 기능 | 현재 코드 | 확인되지 않은 것을 대신하지 않음 |
|---|---|---|
| 로컬 관제·보고서 | 네 카드, 일반 권한 파일 수집, 자원 API·추이·내보내기 | 실제 사용자 PC의 모든 센서 지원, 전체 OS 안전 |
| 본인 SDP 조회·판정 | 호스트·어댑터·서버·화면 연결 경로 | 운영 인증서 발급 및 원천 정책 성공 |
| 앱 AI | 승인·모델 목록·사건 설명·학습지원 경로 | 운영 계정 권한·유료 추론 성공 |
| 사람 확인 조치 | 준비·확인·집행 요청·결과 원장 경로 | 기본 활성화, 실제 대상의 효과 확인 |
| 공개 패키지 조회 | 허용된 정확 버전의 OSV 대조 | 전체 의존성 안전, 침해 부재 |

## 재현 기록

하나의 소스 커밋·Node 버전·OS·실행 모드를 기준으로 결과를 적습니다. 미연결·미지원·실패를 성공으로 합산하지 않고, DEMO·합성 응답·CI 머신·사용자 PC를 명시합니다. 종료 후 같은 폴더에서 재실행하여 동일한 절차를 확인합니다. 기존 폴더와 제출물은 유지합니다.

[STUDENT_RELEASE_RECORD.md](STUDENT_RELEASE_RECORD.md) 및 [STUDENT_REPRO_EVIDENCE.json](STUDENT_REPRO_EVIDENCE.json)은 기록된 시점의 증적입니다. 이번 문서 개정은 그 결과나 공식 단계 상태를 바꾸지 않습니다.
