재현 및 심판 제출 절차

관측 사실과 학습용 로컬 시험을 구별합니다.

  1. 로그인 전 작전실을 갱신하여 금지 요청의 실제 거부 상태를 관측합니다.
  2. 공식 계정으로 로그인한 뒤 다시 갱신하여 정상 메모 조회의 허용 여부를 확인합니다.
  3. 각 행의 기대값·실제 HTTP 코드·요청 ID·시간을 독립 서버 기록과 대조합니다.
  4. 엔진 판정·탐지·회수·복구와 41종 시험은 공식 결과를 확보하기 전까지 미실행입니다.
