## 관측과 원천의 한계

- 로컬 API는 **Node 서버 실행 환경**, 파일 보고서는 **사용자가 선택한 수집기 환경**입니다. 두 환경이 같은 물리 PC라고 인증하지 않습니다.
- 파일은 원본 미인증 자료입니다. 문자열 schema/source나 사용자 확인 체크가 서명·기기 식별을 대신하지 않습니다.
- 네트워크 수집은 Node 인터페이스/주소와 resolver DNS입니다. 기본 게이트웨이·전체 라우팅표·모든 어댑터 DNS·패킷은 미수집입니다.
- 방화벽은 특정 관리 도구의 조회 범위입니다. Windows ActiveStore 프로필은 활성 네트워크 프로필·모든 규칙·타사 제품 전체의 증명이 아닙니다.
- Windows 로그는 24시간 Level 2/3 건수이며 로그별 2,000건 상한이 있습니다. 0건·미조회·권한 실패·상한 초과를 구별합니다. 침해/공격 탐지와 인과 분석이 아닙니다.
- CPU·메모리·디스크 수치는 OS 회계 방식·가상화·캐시·파일시스템 의미에 영향을 받습니다. 특정 관리 도구와 수치가 완전히 같다고 약속하지 않습니다.

## 미확인 운영 사실

[서버](../on-client/src/server.mjs)에 경로가 존재한다는 사실만으로 운영 SDP·앱 자격·유료 AI·실제 원천 조치 효과·실제 사용자 Windows/macOS/Linux 수용·공식 평가를 확정하지 않습니다. 기본 미연결과 시험 DEMO는 별도 상태입니다.

Native 계정·자격 보관에는 Windows 전용 경계가 있습니다. Mac/Linux 기본 관제 지원을 모든 인증 경로의 호환성으로 확대하지 않습니다. 루트 AI/위협정보 API는 로컬 앱의 조건부 AI/OSV와 별개이며 현재 501 경로입니다.

`.github/workflows/quality.yml`은 특정 Node 기준의 합성·로컬 검사와 브라우저/Windows 실행을 정의합니다. 워크플로 파일이 있다는 사실은 실행 결과가 아닙니다. 성공 결과도 그 SHA·실행 환경·시험 범위에만 적용됩니다. 공개 배포와 수업 포털 상태는 현재 원천을 별도로 확인해야 합니다.
